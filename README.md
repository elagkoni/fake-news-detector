# Fake News Detection System

## Overview
This project was developed as the second assignment for the **Data Mining Techniques** course (Spring 2020-2021) at the National and Kapodistrian University of Athens.

It focuses on analyzing news articles and building machine learning models to distinguish between fake and true news.

## Objectives
- **Data Analysis:** Explore and visualize fake and true news articles.
- **Text Preprocessing:** Clean and prepare text data for classification.
- **Text Representation:** Use BoW, TF-IDF, and Word2Vec.
- **Classification:** Compare Logistic Regression, Naive Bayes, SVM, and Random Forest.
- **Evaluation:** Compare models using Accuracy and F1 score.
